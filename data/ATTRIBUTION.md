The Concrete cache uses CSV format and normalized column labels instead of the original spreadsheet format. That storage-format adaptation is disclosed here. The cached data bytes were preserved in this preparation; the numeric equivalence of the cache to a freshly retrieved official spreadsheet was not independently rechecked in this review. Analysis transformations, including the water-to-binder ratio, are recorded separately in the experimental protocol.

Retain dataset attribution, source links, the licence reference and change indications when redistributing these data. The project's software MIT licence does not replace the datasets' CC BY 4.0 terms. The use of these data does not imply endorsement by their contributors.

The archived `sensitivity` comparator has its own GPL-2 notice and licence text, and the official FIRST reference source is not included here. See the [third-party source notice](../results/numerical_20261001/reference_source/NOTICE.md).
