# Observed-Data Snapshots

The cached files support the observed-data experiments without a network
download. They are redistributed under the UCI Machine Learning Repository's
Creative Commons Attribution 4.0 International license.

| Local file | Dataset | UCI record | DOI |
|---|---|---|---|
| `real_data_cache/concrete.csv` | Concrete Compressive Strength | https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength | 10.24432/C5PK67 |
| `real_data_cache/airfoil_self_noise.dat` | Airfoil Self-Noise | https://archive.ics.uci.edu/dataset/291/airfoil+self+noise | 10.24432/C5VW2C |
| `real_data_cache/auto-mpg.data` | Auto MPG | https://archive.ics.uci.edu/dataset/9/auto+mpg | 10.24432/C5859H |

The Concrete data originate from I-Cheng Yeh's 1998 study; Airfoil Self-Noise
was contributed by Thomas Brooks, D. Pope, and Michael Marcolini; Auto MPG was
contributed by R. Quinlan. See the UCI records for complete attribution and
variable definitions.
